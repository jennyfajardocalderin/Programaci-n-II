# Ejercicio Netflix - Programación Orientada a Objetos

Proyecto base para trabajar lectura de ficheros CSV, herencia, colecciones y mapas en Java.

## Importar en Eclipse

1. Descargar o clonar este repositorio.
2. Abrir Eclipse.
3. Ir a `File > Import`.
4. Seleccionar `General > Existing Projects into Workspace`.
5. Elegir la carpeta del proyecto.
6. Pulsar `Finish`.

## Fichero de datos

El fichero `programas.csv` debe estar en la raíz del proyecto.

## Ejercicio 1

Implementar en la clase `NetxflixProgramacion` el método `cargarProgramasCSV`, que debe leer el fichero `programas.csv` y crear objetos `Movie` o `TVShow` según la última columna del CSV.
